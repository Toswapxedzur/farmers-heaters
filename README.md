# Farmers Heaters

A Minecraft 1.21.1 NeoForge addon that adds fuel requirements to Farmer's Delight cooking.

## Compatibility

- Minecraft 1.21.1
- NeoForge
- Farmer's Delight
- Central Heater
- My Nether's Delight is optional

## Development

Use JDK 21, then run:

```sh
./gradlew build
```

Local Gradle caches, IDE settings, and Minecraft test-world output are intentionally ignored by Git.
